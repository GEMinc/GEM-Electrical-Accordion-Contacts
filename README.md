# HTML Hello World Project

This project is a simple "Hello World" webpage created using HTML. It serves as a basic example of how to structure an HTML document.

## Files

- `index.html`: Contains the HTML structure of the webpage, displaying "Hello World".
- `README.md`: This documentation file provides an overview of the project and instructions on how to view the webpage.

## How to View the Webpage

1. Open the `index.html` file in a web browser.
2. You should see the message "Hello World" displayed on the page.
